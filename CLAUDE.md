# Shared BarCorp knowledge base

This project is BarCorp's **BarScrapper (web line)**. There's a shared markdown
knowledge base across all BarCorp sandboxes at:

```
C:\Users\fadzilah akbar\knowledge\brain-store
```

Read `_README.md` there for the full convention. The short version: **every
time there's meaningful progress or a decision worth remembering on this
project**, write it as a new markdown file straight into that store's
`barscrapper-web/` subfolder (never `officebar/` or the other lines' folders —
those belong to other BarCorp sandboxes). No special tool needed, just write
the `.md` file directly to that path. Other BarCorp sandboxes (officeBAR,
BarScrapper-ext, BarTrading) read from the same tree, so this is how
knowledge stays shared without a sync step.
